## A note on case order in Part II

The cases appear in the chronological order of the conversations that produced them, not in case-number order: Case 44 appears between Cases 41 and 42, followed by Case 43, then Case 45 onward. This ordering is deliberate and is explained in the Part II headnote. It is not an error, and it matches the published PDF exactly.
